# concept-learning-lab

> **大数据与人工智能 · 概念学习实验仓库**
> 本仓库用于"个人学习设计"实验：定义可复用的概念学习 **Skill**，用它在 `learning-materials/` 下沉淀一份份结构化的个人学习资料，并梳理概念之间的联系。

---

## 1. 仓库用途说明

这个仓库是我用来实践 **"用 AI 辅助个人深度学习"** 的实验场，核心思路是：**把"怎么学会一个新概念"这件事本身，沉淀成一个可复用的 Skill（concept-learner），再反复调用它去生成高质量的学习资料。**

- 不只记录"学到了什么"，更记录"**用什么方法学会的**"；
- 每份学习资料都按同一套 **个人学习设计** 工作流产出（行为化目标 → 驱动式问题 → 建直觉 → 讲机制 → 动手/自测 → 复盘），而不是零散的概念堆砌；
- 已经学习了 **Agent、上下文（Context）、Skill** 三个互相联系的核心概念，并产出一份三者的关系说明。

---

## 2. Skill 存放路径

本仓库使用了一个 **项目级 Skill**：`concept-learner`（概念学习者），用于"自动生成任意概念的个人学习资料"。

**文件位置：**
```
.workbuddy/
└── skills/
    └── concept-learner/
        └── SKILL.md      ← 技能定义（YAML 元数据 + 适用场景 + 输入要求 + 7 步工作流 + 自检项）
```

> 💡 `concept-learner` 就是一个标准的 Agent Skill：`SKILL.md` 顶部带 `name` + `description`（元数据），正文写明工作流与输出规范。它存在于 `.workbuddy/skills/` 下，属于**本仓库项目级**技能。

---

## 3. 如何在 WorkBuddy 中调用这个 Skill

在 WorkBuddy 对话中，`concept-learner` 会根据你描述的任务被自动识别并按需加载。你可以用以下方式触发它：

**方式 A：直接点名要用它（推荐）**
> “**调用 concept-learner Skill**，帮我学习『向量数据库』这个概念。”

**方式 B：只说学习需求，让它自动匹配**
> “用个人学习设计的方法，做一份关于『RAG』的中文学习资料，保存成 HTML。”

> 当任务命中 Skill 的 `description`（“自动生成任意概念的学习资料”）时，WorkBuddy 会自动加载 `SKILL.md` 并按其工作流执行，产出放到 `learning-materials/`。

**生成一份学习资料的标准对话流程示例：**
```
你： 调用 concept-learner，学习「大模型微调」概念，输出为 learning-materials/finetuning.html
AI：  按 SKILL.md 工作流执行 → ①搜真实权威来源 → ②生成 HTML(含学习目标/核心问题/
     个人化解释/核心机制/应用场景/边界辨析/自测/资料来源) → ③保存到 learning-materials/ 
你： 完成后可要求 git add + commit，把新资料纳入版本管理。
```

> 📌 说明：本项目产出的学习资料文件名建议使用**小写英文**（如 `agent.html`、`llm-context.html`），避免中英文路径问题；并在 `<title>`/正文标注中文主题，便于人眼识别。
